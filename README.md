# 每日学习任务安排

一个面向个人学习的**单页网页应用**：按三个固定学习时段(上午 / 下午 / 晚上)安排任务、打卡，并内置学习计时器与铃声提醒。

> 在线预览：<https://js-jc.github.io/daily-study-schedule/>（由 GitHub Pages 托管，手机可直接打开）

## 功能

- **三个学习时段**：上午 08:00–12:00、下午 14:00–18:00、晚上 19:30–22:30，每时段默认 3 条学习任务
- **任务打卡**：点击任务前的勾选框即可标记"已完成"，实时显示进度条与完成百分比
- **学习计时器**：自由设定学习/休息时长(支持 25/45/60/90/120 等快捷档)，圆形倒计时，学习和休息自动切换
- **每日签到**：一键签到，统计连续/累计签到天数，内置月历可回看历史签到记录
- **铃声提醒**：每个时段开始/结束时、番茄钟休息到点均播放"开始音/结束音"两种不同提示音并弹窗
- **本地数据**：打卡、签到、时长设置等均保存于浏览器 localStorage，关闭重开不丢失
- **纯前端、零依赖**：单 HTML 文件即可运行，无需安装任何软件

## 如何使用

### 在线方式
直接打开上方的在线链接即可使用。

### 本地方式
用任意浏览器打开 `index.html` 即可，无需服务器。

> 提示：为保证铃声能播放，页面打开后请**先点击一下页面任意处**开启声音权限；并保持页面处于打开状态，到点的铃声与弹窗才会生效。

## 目录

- `index.html` —— 应用本体(单文件)
- `每日学习任务安排.html` —— 同上(旧文件名副本)

## 技术说明

HTML + CSS + JavaScript 单文件实现；声音通过 Web Audio API 实时合成，无需任何音频素材文件；数据使用 localStorage 持久化。

## 许可

仅供个人学习使用。
